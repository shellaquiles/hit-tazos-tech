# Categoría B3: Herramientas Dev y Control de Versiones (1976 – 2024)

| # | Hito / Pista (Frente) | Año (Reverso) | Creador / Bonus | Dato Curioso |
| :--- | :--- | :---: | :--- | :--- |
| **#B3-001** | Creación de **SCCS** (*Source Code Control System*), el primer sistema automatizado de control de versiones de código de la historia. | **1972** | *Marc Rochkind* (*Bell Labs*) | Diseñado para computadoras IBM sobre tarjetas perforadas; almacenaba el historial mediante *deltas* entrelazados para ahorrar espacio en discos magnéticos de escasos megabytes. |
| **#B3-002** | Nacimiento del editor de texto extensible **Emacs** en el laboratorio de inteligencia artificial del MIT. | **1976** | *Richard Stallman* y *Guy L. Steele Jr.* (*MIT AI Lab*) | Stallman lo concibió como un conjunto de macros de edición (*Editing MACroS*) sobre el editor TECO; su capacidad de ser reprogramado en dialectos Lisp lo convirtió en un sistema operativo en sí mismo. |
| **#B3-003** | Desarrollo de **Vi**, el editor modal de pantalla completa incluido en la primera distribución BSD de Unix. | **1976** | *Bill Joy* (*UC Berkeley*) | Diseñado para terminales lentas de 300 baudios; Joy asignó los comandos de navegación `h`, `j`, `k`, `l` porque el teclado del terminal *Lear Siegler ADM-3A* tenía flechas impresas sobre esas teclas. |
| **#B3-004** | Aparición de **RCS** (*Revision Control System*), popularizando el bloqueo estricto de archivos por usuario en entornos Unix. | **1982** | *Walter F. Tichy* (*Purdue University*) | Almacenaba las revisiones como deltas inversos para que consultar la última versión fuera casi instantáneo, convirtiéndose en el motor estándar de los primeros servidores compartidos. |
| **#B3-005** | Creación de **CVS** (*Concurrent Versions System*), permitiendo a múltiples programadores modificar un mismo archivo en paralelo. | **1986** | *Dick Grune* | Nació como una serie de scripts de shell que envolvían a RCS; su modelo de fusión optimista sustituyó para siempre la pesadilla de bloquear archivos completos durante días. |
| **#B3-006** | Publicación de **Vim** (*Vi IMproved*) para computadoras Commodore Amiga bajo un modelo de software benéfico (*charityware*). | **1991** | *Bram Moolenaar* | En lugar de pedir donaciones para sí mismo, Bram solicitaba a los usuarios enviar dinero a orfanatos de niños en Uganda, manteniendo esta causa humanitaria activa durante más de tres décadas. |
| **#B3-007** | Nacimiento de **Subversion** (**SVN**), diseñado para corregir las graves deficiencias estructurales de CVS. | **2000** | *CollabNet* (*Jim Blandy* y *Karl Fogel*) | Introdujo confirmaciones de cambios atómicas (*atomic commits*) y soporte para renombrar carpetas y versionar archivos binarios sin corromper el historial del repositorio. |
| **#B3-008** | Lanzamiento de **IntelliJ IDEA**, revolucionando los entornos de desarrollo integrados con autocompletado y refactorización semántica avanzada. | **2001** | *JetBrains* (*Sergey Dmitriev* y *Valentin Kipiatkov*) | Fue el primer IDE en entender el árbol sintáctico del código en memoria para proponer refactorizaciones seguras en Java, cobrando una licencia comercial en una época de IDEs gratuitos. |
| **#B3-009** | Debut de **TextMate** para Mac OS X, redefiniendo la estética y ergonomía de los editores con snippets dinámicos y navegación difusa. | **2004** | *Allan Odgaard* (*MacroMates*) | Su sistema de coloreado de sintaxis basado en expresiones regulares de *Oniguruma* y su comando `Cmd+T` para abrir archivos rápidamente inspiraron directamente a editores posteriores. |
| **#B3-010** | Creación urgente de **Git** como sistema de control de versiones distribuido tras la crisis con el software propietario *BitKeeper*. | **2005** | *Linus Torvalds* | Linus programó el núcleo funcional basado en un grafo acíclico dirigido (*DAG*) en solo dos semanas, asombrando a la industria por su velocidad de cálculo de ramas y fusiones. |
| **#B3-011** | Lanzamiento de **Mercurial** (**hg**), concebido la misma semana que Git como alternativa distribuida escrita en Python y C. | **2005** | *Matt Mackall* | Se disputó con Git el control del kernel Linux; aunque Linus eligió su propia creación, gigantes como *Facebook* y *Google* operaron monorepositorios colosales sobre Mercurial. |
| **#B3-012** | Aparición de **Sublime Text**, conquistando a los desarrolladores por su velocidad instantánea y su minimapa lateral de código. | **2008** | *Jon Skinner* | Programado en C++ y Python para ofrecer una interfaz ligera y sin lag; popularizó la función de selección con múltiples cursores simultáneos (`Ctrl+D`). |
| **#B3-013** | Lanzamiento del editor **Atom** por parte de GitHub bajo el lema *"A hackable text editor for the 21st Century"*. | **2014** | *GitHub* (*Chris Wanstrath*) | Para construirlo crearon internamente la plataforma *Electron* (combinando Chromium y Node.js), tecnología que más tarde impulsaría aplicaciones como Slack, Discord y VS Code. |
| **#B3-014** | Creación del proyecto **Neovim**, una bifurcación agresiva de Vim enfocada en limpiar la base de código en C y añadir soporte para scripting en **Lua**. | **2014** | *Thiago de Arruda* | Nació tras el rechazo de Bram Moolenaar a aceptar parches para refactorizar la arquitectura interna; Neovim revivió el entusiasmo por los editores de terminal entre las nuevas generaciones. |
| **#B3-015** | Presentación de **Visual Studio Code** (**VS Code**), convirtiéndose en el editor de código más adoptado del planeta. | **2015** | *Microsoft* (*Erich Gamma*) | Creado por uno de los autores del libro de *Design Patterns*, sorprendió al mundo al ser gratuito, de código abierto y compatible con Linux, macOS y Windows desde el día uno. |
| **#B3-016** | Estandarización del protocolo **LSP** (*Language Server Protocol*), desacoplando la inteligencia de compiladores de la interfaz del editor. | **2016** | *Microsoft*, *Red Hat* y *Codenvy* | Permitió que un único servidor de lenguaje (como *pyright* o *gopls*) proveyera autocompletado, diagnósticos y salto a definiciones para cualquier editor de texto compatible. |
| **#B3-017** | Apertura de la vista previa de **GitHub Copilot**, inaugurando la era de la programación asistida por modelos de inteligencia artificial generativa. | **2021** | *GitHub* y *OpenAI* (*Nat Friedman*) | Entrenado sobre miles de millones de líneas de código público con el modelo *Codex*, introdujo la autocompletación predictiva de funciones completas en tiempo real. |
| **#B3-018** | Presentación pública de **Zed**, un editor de código colaborativo de latencia ultra baja programado íntegramente en lenguaje **Rust**. | **2023** | *Nathan Sobo* (*Zed Industries*) | Creado por los diseñadores originales de Atom, abandonó Electron para renderizar texto directamente mediante la tarjeta gráfica (GPU), alcanzando 120 fotogramas por segundo fluidos. |
| **#B3-019** | Fallecimiento de **Bram Moolenaar**, conmocionando a la comunidad global de desarrollo tras 32 años de custodia ininterrumpida de Vim. | **2023** | *Comunidad Mundial de Software Libre* | Millones de programadores le rindieron homenaje en redes y terminales; en su testamento legó los derechos y fondos del proyecto para continuar su obra caritativa en África. |
| **#B3-020** | Lanzamiento y explosión de adopción del editor **Cursor**, integrando capacidades agénticas de IA con indexación semántica del repositorio. | **2024** | *Anysphere* | Construido como una bifurcación de VS Code, introdujo la edición de múltiples archivos coordinados y la predicción multi-línea mediante modelos de lenguaje locales y en la nube. |
